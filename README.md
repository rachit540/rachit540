## 🔨 What I'm working on

**[MEDQR](https://github.com/rachit540/MEDQR)**
Generates QR codes that link to a patient's emergency medical profile — blood type, allergies, medications, emergency contacts. The idea: one scan and first responders have what they need. Built with React 19 + Vite + Tailwind on the frontend, Node/Express + LowDB on the backend.

**[Color Detection ML](https://github.com/rachit540/Color-Detection-ML-project)**
Real-time color tracking using Python + OpenCV and a webcam. Spent way too long fighting Windows camera backend issues before switching to DirectShow with auto-scan detection — now it actually works. Small project, but I learned more debugging it than building it.

**AKTU Physics PYQ Analyzer** *(in progress)*
A revision tool for AKTU Engineering Physics — it maps out which topics appear most in past year questions so students know where to actually focus. React/Vite + Supabase. Building this because I needed it.
